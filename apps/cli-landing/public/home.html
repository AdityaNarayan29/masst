A real product,
not a starter template.
Auth, multi-tenancy, a dashboard and a typed database, wired together in a Turborepo monorepo you own outright.

04 · Quickstart
Three steps.
About a minute.
You’ll need Node.js, pnpm and Docker installed.

  

    
Install
Add the CLI globally so the short mst command is available.
$npm i -g @masst/cli

    
Scaffold
Create the monorepo, initialise git and install every dependency.
$mst init my-app

    
Launch
Start Docker, prepare the database and run the web app and API together.
$cd my-app && mst dev

  

  
Prefer not to install anything? npx @masst/cli init my-app works too. Sign in to the demo with demo@example.com / demo123.
